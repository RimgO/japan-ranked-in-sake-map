# 評価の高い日本酒の蔵 — 産地・甘辛・米・水

SAKETIME総合ランキング上位50銘柄を醸す43蔵を日本地図に置き、日本酒度・酸度、使用米、仕込み水との関係を見られるインタラクティブな可視化です。

公開ページ: https://rimgo.github.io/japan-ranked-in-sake-map/

## 見られるもの

- **蔵の地図** ― 色分けを「評価点 / 味の傾向 / 日本酒度 / 主な米 / 仕込み水」で切り替え。点をクリックすると代表商品・米・水の詳細を表示
- **日本酒度 × 酸度** ― 数値が公開されている蔵の代表商品を散布図に
- **米と日本酒度** ― 米の種類ごとに日本酒度を並べ、中央値を表示
- **米 → 仕込み水 → 銘柄 → 日本酒度 のサンキー図** ― 1本の帯が1蔵。箱を押すとそこを通る蔵を強調、帯の色は米/日本酒度で切り替え
- **仕込み水** ― 記載のあった蔵の水源と水質の一覧
- **全蔵の一覧**

## データ

- `data/kura.csv` / `data/kura.json` ― 43蔵ぶんのデータ(順位、評価点、代表商品、日本酒度、酸度、米、仕込み水、味の傾向、所在地)
- 出典: [SAKETIME 日本酒ランキング](https://www.saketime.jp/ranking/)と各銘柄ページ(2026年11月24日閲覧)
- 緯度・経度は所在地の市町村から置いた概略値です
- 地図の輪郭: [dataofjapan/land](https://github.com/dataofjapan/land) を簡略化したもの(沖縄・小さな島は省略)

## 注意点

- 日本酒度・酸度は蔵ごとに代表商品1本の値で、商品や醸造年で変わります
- 新政・産土・Ohmine など数値を公開していない蔵は「非公開」としています
- 「味の傾向」は説明文とレビューの甘辛評価から3段階に分けたものです

## 構成

ビルド不要の静的サイトです。`index.html` をブラウザで開くだけで動きます。

- `js/app.js` ― 描画コード(d3 v7)
- `js/sankey.js` ― サンキー図
- `js/dash-shim.js` ― データの受け渡しと再描画
- `js/d3.v7.min.js` ― d3(同梱)
